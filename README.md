## 📌 Загальна інформація

- **Тип проєкту**: Веб-застосунок і консольні сценарії для класифікації сенсорних сигналів
- **Мова програмування**: Python 3.12
- **Фреймворки / Бібліотеки**: Flask, TensorFlow/Keras, scikit-learn, XGBoost, OpenCV, scikit-image, PyWavelets, NumPy, Pandas, Matplotlib
- **Дані**: 445 PNG-знімків осцилограм (тека `dataset/`); ознаки, результати та моделі зберігаються у файлах CSV, PKL і KERAS
- **Класи**: ацетон (`acetone`), аміак (`ammonia`), етанол (`ethanol`), фонова атмосфера з відносною вологістю (`RH`)

---

## 🧠 Опис функціоналу

- 🖼️ **Обробка знімка**: Обрізання інтерфейсу осцилографа, виділення кривої HSV-маскою, перетворення маски на одновимірний сигнал
- ✂️ **Сегментація на імпульси**: Пошук фронтів методом гістерезису за рівнем і поділ сигналу на повні цикли
- ✅ **Контроль якості**: Відкидання імпульсів зі зниклою кривою, надмірним шумом або неправильною шириною
- 🔢 **Гілка ознак**: 35 числових ознак імпульсу і сім моделей (LogReg, KNN, SVM, DecisionTree, RandomForest, GradientBoosting, XGBoost)
- 🧩 **Гілка зображень**: Вхід 192×96×2 (напівтоновий канал і маска кривої), HOG-дескриптори, заморожена MobileNetV2 і власна згорткова мережа 2D-CNN
- 🎯 **Злиття рішень**: Об’єднання прогнозів імпульсів у рішення для знімка з вагою за якістю імпульсу; ансамблі моделей
- 📊 **Експерименти**: Групова крос-валідація GroupKFold(5) за знімком і зведена таблиця всіх моделей
- 🌐 **Веб-інтерфейс**: Класифікація нового знімка будь-якою моделлю чи ансамблем з покроковою візуалізацією обробки

---

## 📊 Основні результати

| Модель | F1-macro (рівень знімка) |
|--------|--------------------------|
| Ансамбль HOG + XGBoost і 2D-CNN | 0,980 ± 0,004 |
| 2D-CNN | 0,977 ± 0,007 |
| SVM на числових ознаках | 0,930 ± 0,023 |

Оцінювання виконано на 445 знімках (1253 імпульси) груповою крос-валідацією GroupKFold(5).

## ▶️ Як запустити проєкт "з нуля"

### 1. Клонування репозиторію

```bash
git clone https://github.com/We1zer/sensor_image_classification.git
cd sensor_image_classification
```

### 2. Створення віртуального середовища і встановлення залежностей

```bash
python -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # Linux / macOS
pip install -r requirements.txt
```

Версії пакетів у `requirements.txt` зафіксовано навмисно, оновлювати їх не рекомендується.

### 3. Побудова набору імпульсів і навчання базових моделей

```bash
python app.py
```

У меню оберіть пункт **8** «Запустити повний pipeline». Він індексує набір даних, обробляє знімки, вирізає імпульси, обчислює ознаки, навчає моделі гілки ознак і будує графіки в `results/`.

### 4. Навчання моделей для класифікації нових знімків

```bash
python -m src.feature_model_store
python -m src.image_model_store
```

Перша команда навчає сім моделей гілки ознак, друга – моделі гілки зображень (HOG, MobileNetV2, 2D-CNN) та ансамблі. Найдовший крок – навчання 2D-CNN на CPU.

### 5. Запуск застосунку

```bash
python webapp.py
```

Відкрийте браузер: `http://127.0.0.1:5000`

## 🖱️ Інструкція для користувача

### 1. **Головна сторінка (`/`)**
- Стан проєкту: кількість знімків, наявність ознак і навчених моделей
- Кнопки швидких дій

### 2. **Набір даних (`/dataset`)**
- Кількість знімків за класами та їх перегляд
- Переіндексація набору після додавання файлів

### 3. **Побудова ознак і навчання (`/pipeline`, `/training`)**
- Побудова набору імпульсів і ознак (фонова задача з індикатором прогресу)
- Навчання та порівняння моделей гілки ознак

### 4. **Експерименти (`/experiments`)**
- Запуск гілки ознак і гілки зображень
- Зведена таблиця всіх моделей

### 5. **Класифікація знімка (`/predict`)**
- Завантажте PNG-файл осцилограми
- Оберіть модель або ансамбль (поруч із назвою вказано F1-macro моделі)
- Натисніть кнопку класифікації

### 6. **Сторінка результату**
- **Фінальний клас** і впевненість
- **Ймовірності за класами** і прогноз для кожного імпульсу
- **Покрокова обробка**: рамка обрізання, маска, сигнал із порогами, межі імпульсів
- **Таблиця фрагментів**: рішення контролю якості та вхід моделі для кожного фрагмента

### 7. **Інтерпретація результатів**
- 🟢 **Впевненість ≥ 0,55**: рішення надійне
- 🟡 **Впевненість < 0,55**: система виводить попередження, знімок варто перевірити

### 8. **Командний рядок**

```bash
python -m src.predict dataset/PNG-1ethanol/SDS00050.png
python -m src.predict_image dataset/PNG-1ethanol/SDS00050.png "2D-CNN"
python run_experiments.py --branch both
python -m src.compare_all --with-cnn
```

## 🧪 Проблеми і рішення

| Проблема | Рішення |
|----------|---------|
| Імпульси одного знімка потрапляли в навчальну й тестову вибірки, завищуючи точність | Групова крос-валідація GroupKFold з групуванням за знімком |
| 2D-CNN з BatchNorm у режимі прогнозу давала F1 0,11 | Заміна на GroupNormalization, що нормалізує кожен зразок окремо |
| Розтягування імпульсу до квадрата спотворювало його форму | Вхід 192×96 зі збереженням пропорцій і другим каналом – маскою кривої |
| Стандартні віддзеркалення під час аугментації руйнували форму імпульсу | Лише зсуви, масштабування ±10 % і зміна контрасту |
| Шум сигналу давав хибні межі імпульсів | Пошук фронтів гістерезисом за рівнем |
| Пошкоджені фрагменти сигналу потрапляли в модель | Контроль якості імпульсу за чотирма правилами |
| Windows Smart App Control блокує DLL пакетів | Зафіксовані версії пакетів; за потреби вимкнути Smart App Control або запускати в Linux, WSL чи Google Colab |
| keras 3.15+ несумісна з TensorFlow 2.17 | Версія `keras==3.6.0` |
